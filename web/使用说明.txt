Codex Remote Web · 远程设备

解压到可写目录。客户端需要 Node.js（已验证 24.16.0）。首次使用时按启动脚本提示在浏览器完成 Remote 设备授权。也可以在解压目录手动运行 node transport.mjs --authorize。请使用能看到目标设备的 Remote 账号。运行 node transport.mjs --authorize list 可查看当前支持的授权方式。
Windows 双击 start.cmd 即可开始；脚本会检查 Node.js，沿用或申请 Remote 设备授权，授权成功后启动服务并打开默认浏览器。也可以在该目录运行 node server.mjs，再手动访问 http://127.0.0.1:47831/ 。使用期间保留服务进程。同一接收设备的多个浏览器窗口请打开同一个服务地址。同时启动使用同一 Remote 设备身份的第二个服务，可能使前一个服务的事件连接被主机替换。其他电脑或平板请在各自设备上完成 Remote 设备授权。安卓 Termux 是待实机验证的接收环境，需要可运行当前包的 Node.js；在 Termux 私有目录解压后运行 sh start.sh。脚本会检查 Node.js、沿用或申请 Remote 授权，然后启动接收端并请求打开浏览器。若浏览器没有自动打开，用同一台设备访问终端打印的本地地址。在支持安装网页应用的浏览器菜单中选择安装或添加到主屏幕。以后使用同一浏览器和端口，保留草稿与聊天记录。
首次打开网页后选择在线设备。切换设备时，点击左侧栏顶部的主机名称，从下拉列表选择设备。页面记住上次使用设备的 ID，设备离线时可选择其他主机。正在运行的旧任务仍属于原主机。各主机的任务状态分开保存在 state/devices 下。Linux 运行 sh start.sh。图形桌面通过 xdg-open 打开授权页和本机工作台，无图形桌面时使用终端打印的地址。已在 WSL2 Ubuntu 22.04、Node.js 26.2.0 验证首次授权入口和本机选机页。
普通聊天默认沿用主机权限，可在输入框的权限菜单中针对当前聊天调整。旧版原生 Codex 插件使用「请求批准」。未选项目时，原生主机使用其返回的首个有目录的项目，指定工作目录请先选择项目。原生主机通过 Remote 持续推送正文，接收端定期核对轮次状态。事件连接不可用时，接收端改为读取当前轮次。Codex 与 OpenAI 登录由各自的主机提供。
